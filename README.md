# 🧠 Fika NeuroLab — Projeto Web Front-End

Repositório dedicado ao desenvolvimento do site do **Fika NeuroLab**, um projeto acadêmico focado em inclusão, acessibilidade e neurodiversidade no mercado de tecnologia, desenvolvido para a faculdade de Análise e Desenvolvimento de Sistemas (ADS).

🚀 **Acesse o projeto online:** [Executar a Aplicação (GitHub Pages)](https://severiano-mateus.github.io/fika-neurolab-unicsul/)

---

## 📝 Sobre o Projeto e Motivação

Sempre fui apaixonado por criação de sites. No passado, explorei plataformas como Blogspot e Tumblr para criar publicações e comunidades sobre jogos. Estudar front-end nesta etapa da faculdade foi uma experiência extremamente satisfatória, que reacendeu essa paixão por transformar ideias em código e interfaces reais.

O **Fika NeuroLab** nasce da união entre tecnologia, design e propósito social. O objetivo da plataforma é conectar mentes neurodivergentes a oportunidades no mercado de TI, promovendo acessibilidade, capacitação técnica e conscientização corporativa.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico:** Estruturação acessível e otimizada para leitores de tela.
- **CSS3 Moderno:** Layout responsivo (Grid/Flexbox), variáveis CSS (*Design Tokens*) e suporte a modo de Alto Contraste.
- **JavaScript (ES6+):** Arquitetura *Single Page Application* (SPA) nativa, validação dinâmica de formulários e manipulação do `localStorage`.
- **Git & GitHub Pages:** Versionamento de código e deploy com integração/entrega contínua (CI/CD).

---

## ♿ Recursos de Acessibilidade

- Controles para aumento e diminuição do tamanho da fonte.
- Alternância para tema de **Alto Contraste**.
- Navegação por teclado e atalhos de salto direto ao conteúdo (`skip-link`).
- Estrutura acessível compatível com as diretrizes da eMAG / WCAG.
